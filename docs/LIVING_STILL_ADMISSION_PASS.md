## Deliberate differences from the capture

Two, both load-bearing:

1. **No `<library location=…>` wrapper**, and no `<smart-collection>` elements.
   Those are artefacts of exporting *from* a library. A probe naming a library
   on disk would be pointing the import at it, which crosses the line this
   project keeps between generating a file and driving Final Cut. The bare
   `<event>` form is what all four dissolve revisions imported with.
2. **No `asset/@uid` and no `media-rep/@sig`.** Final Cut assigns those on
   ingest. Inventing them would assert an identity we were never given.

If either turns out to matter, the returned file will say so.

## Reading the result

| Returned state | Meaning |
| --- | --- |
| crash during import | the still path fails where the dissolve's `asset-clip` path failed; record the stack |
| no project, or an empty spine | the `<video>` construction was rejected outright |
| `<video>` present, no `adjust-transform` | keyframed intrinsics not admitted from a generated file |
| `position` flattened to one param, or `scale` split into X/Y | Final Cut normalised our shapes — the asymmetry is not required after all |
| X value ≠ `3.55556` | the unit conversion is wrong, or Final Cut rescaled it |
| keyframe times not offset from `3600s` | the source-time origin is import-direction-specific |
| `adjust-blend` missing or `amount` dropped | opacity not admitted |
| `effect` uid emptied, or `enabled="0"` | colour effect not instantiated — the revision 2 signature |
| Saturation ≠ 25, or params reordered | the filter was rebuilt rather than accepted |
| everything returns intact | the generated construction is admitted |

## What a pass would admit

**Admission of a generated living still construction.** That is all. It would
not admit editability, it would not admit the composition's own numbers — the
`colorEnrichment` → `Saturation` mapping is still unobserved and the probe
sidesteps it by reusing the captured `25` — and it would not move any
capability gate. `ManualFCPXMLSemanticsEvidence` still defaults to empty and
nothing constructs a non-empty one; see HANDOFF section 6 item 3.

A pass would also not settle whether the three colour payloads are *required*.
This probe carries them. Dropping them is a separate, later experiment.
